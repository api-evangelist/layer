# Layer

> Layer is a living digital art platform — curated, code-based generative and ultra-high-resolution video artwork designed for everyday display. Layer publishes a first-party TypeScript SDK that artists use to build customizable, parameter-driven generative artworks that run and are captured inside Layer Studio.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Layer public developer documentation and the Layer SDK type definitions. Layer exposes an artist-facing client SDK (a browser global, `$layer`), not a public REST/HTTP API.

## SDK surface
- Methods: `params(...params)`, `registerCanvas(canvasElement)`, `preview(video, thumbnail?)`, `startFPSOverlay()`, `stopFPSOverlay()`.
- Parameter types: NUMBER, BOOLEAN, COLOR, LIST, HASH.
- Events: `layer:play`, `layer:pause`, `layer:reset`, `layer:preview`, `layer:parameters`, `layer:paramchange`.
